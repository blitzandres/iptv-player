# IPTV Player

Fast, dark-mode IPTV web player for **Latin America & USA** channels — HLS.js playback, search, favorites, history and custom M3U playlists.

- **Live demo:** [blitzandres.github.io/iptv-player](https://blitzandres.github.io/iptv-player/)
- **Project page:** [andresblitz.com/projects/iptv-player](https://andresblitz.com/projects/iptv-player/)
- **Author:** [Andrés Blitz](https://andresblitz.com/) · [@andresblitz](https://x.com/andresblitz)

## Features

- HLS.js streaming in the browser (no native app)
- Channel search and category filters
- Favorites and watch history (localStorage)
- Custom M3U playlist import
- Dark UI tuned for TV / desktop

## Tech stack

HTML · CSS · JavaScript · [HLS.js](https://github.com/video-dev/hls.js/) · GitHub Pages

## Run locally

Open `index.html` in a browser, or:

```bash
python3 -m http.server 8000
```

Then visit `http://127.0.0.1:8000/`.
